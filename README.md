# Proactive Project Handoff

**Proactive Project Handoff** — пользовательский Skill для ChatGPT, помогающий сохранять контекст длительных проектов, готовить HANDOFF и восстанавливать работу в новых чатах.

Главный принцип: **автоматизировать сохранение состояния, а не принятие решений и не выполнение следующего этапа за пользователя.**

## Текущий статус

Последняя зафиксированная поведенческая приёмка дефекта **T2-01 — Unauthorized Stage Advancement** для версии Skill **v0.1.1**: **PASS по серии R1–R7 (7/7)**.

Это заключение относится к представленным поведенческим сценариям. Оно не является независимым аудитом безопасности, forensic-проверкой побочных эффектов или доказательством корректности во всех возможных условиях.

## Важные ограничения

- Текущая реализация — Skill для ChatGPT; перенос методики на другие платформы требует адаптации и отдельного тестирования.
- Skill не гарантирует фоновую работу и точное обнаружение исчерпания контекстного окна.
- Сам по себе Skill не является постоянным хранилищем и не сохраняет HANDOFF автоматически во внешние системы.
- Следующий шаг из HANDOFF не является разрешением на его выполнение.
- DRAFT / PROPOSED не означает утверждение.
- Неизвестное и непроверенное не трактуется как выполненное.
